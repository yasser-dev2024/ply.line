# القتال مع الأسود 3D

مشروع لعبة Android ثلاثية الأبعاد مبني بمحرك Godot 4.7.1. النسخة الحالية 1.2.2 لعبة مستقلة تعمل دون Godot على هاتف المستخدم.

## الموجود حاليًا

- لاعب ثلاثي الأبعاد بحركة مشي وجري وقفز ودوران تدريجي وكاميرا خلفية.
- تحكم لمس: عصا افتراضية، سحب الكاميرا، جري، قفز، تفاعل، تصويب وإطلاق.
- سلاح منظور كتف ومنظار تكبير قابل للتثبيت ومساعدة تصويب للأطفال وإصابة RayCast وصحة وضرر وفوز وخسارة.
- أسود ثلاثية الأبعاد تتجول وتطارد وتنقض وتهاجم وتسقط عند هزيمتها.
- تحريك إجرائي للأرجل والرأس والذيل، ورياح للأوراق والعشب وماء متحرك.
- خمس مراحل مترابطة: أثر الأسود، كمين النهر، عرين الأسد، القلعة المهدمة ونداء الإنقاذ.
- أهداف مقفلة تشمل الجمع والاستكشاف وعبور النهر وفتح الكهف والقلعة وإنقاذ المستكشف وهزيمة الزعماء.
- حفظ أفضل وقت والمراحل المفتوحة والعملات والمكافآت وإعداد الجودة والحساسية.
- ملف أداء تلقائي للهاتف حقق 30 FPS على الجهاز المتصل أثناء اختبار اللعب.
- APK Release ARM64 موقع، وصفحة تنزيل عربية مستقلة.

## التشغيل على جهاز التطوير

افتح `game/project.godot` باستخدام Godot 4.7.1، أو شغّل المشروع من سطر الأوامر. المستخدم النهائي لا يحتاج إلى Godot؛ يكفي تثبيت APK.

## حدود النسخة الحالية

نموذج الأسد الحالي خفيف ومنخفض التفاصيل لتوافق الجوال. حركته إجرائية وليست حزمة التقاط حركة واقعية كاملة. النموذج الواقعي المهيكل ذو حركات مشي/جري/هجوم منفصلة ما زال تحسينًا مطلوبًا، وكذلك الأصوات الطبيعية والرسوم البشرية النهائية.
