# القتال مع الأسود 3D

لعبة مغامرات ثلاثية الأبعاد للأندرويد مبنية بمحرك Godot 4.7.1، ومصممة بواجهة عربية وتحكم كامل باللمس.

## أهم المميزات

- حملة من خمس مراحل مترابطة، ولكل مرحلة أهداف إلزامية وبيئة وصعوبة ومكافآت مختلفة.
- مشي وجري بسرعات متعددة، قفز، سباحة، استكشاف غابات وأنهار وكهوف وقلعة وحصن إنقاذ.
- أسود متحركة تتجول وتطارد وتهاجم، مع زعماء في المراحل المتقدمة.
- منظار من خط نظر السلاح يخفي جسم اللاعب أثناء التكبير، ويبقى فعالًا بعد الإطلاق حتى يلغيه اللاعب.
- تصويب مساعد مناسب للجوال، ذخيرة وإعادة تعبئة وصحة ومكافآت وحفظ للتقدم.
- إعداد أداء تلقائي للجوال وصفحة تنزيل عربية مباشرة.
- لا تحتوي المراحل على معابد أو محتوى ديني غير مناسب للأطفال المسلمين.

## فتح المشروع

1. ثبّت Godot `4.7.1`.
2. افتح الملف `game/project.godot`.
3. شغّل المشهد الرئيسي أو صدّر نسخة Android من إعدادات التصدير.

توجد تعليمات البناء والتوقيع والتحكم وتراخيص الأصول في مجلد [`docs`](docs/README.md). ملفات مفاتيح التوقيع والبيانات السرية غير مضمّنة في المستودع.
