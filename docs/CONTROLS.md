# التحكم

## Android

- العصا اليسرى: الحركة في جميع الاتجاهات.
- السحب في يمين الشاشة: تدوير الكاميرا.
- جري: الاستمرار على الزر لزيادة السرعة.
- قفز: القفز وتجاوز العوائق.
- تصويب: تقريب الكاميرا خلف الكتف.
- إطلاق: إطلاق السلاح نحو علامة المنتصف.
- تفاعل: فتح بوابة النهاية بعد إنجاز الشروط.
- إيقاف: إيقاف المرحلة واستئنافها أو إعادتها.

## لوحة المفاتيح والفأرة

- `WASD`: حركة، `Shift`: جري، `Space`: قفز، `E`: تفاعل.
- حركة الفأرة: الكاميرا، الزر الأيمن: تصويب، الزر الأيسر: إطلاق.
- `Esc`: إيقاف مؤقت.
